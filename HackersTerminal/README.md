
# 💻 Hacker Terminal Simulation

This is a fun JavaScript practice project that simulates a hacker terminal effect.

## 🚀 Features
- Uses Async/Await
- Random delay using Promises
- DOM manipulation
- Dynamic text rendering
- Terminal-style animation effect

## 🛠 Technologies Used
- HTML
- CSS
- JavaScript (ES6)

## 📚 Purpose
Built for practicing:
- Async functions
- Promises
- setTimeout
- DOM manipulation
